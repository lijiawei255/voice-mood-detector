## 📖 项目简介

语音情绪识别系统是一款基于深度学习的桌面应用程序，通过麦克风录制用户的语音，使用 emotion2vec+ 系列大模型智能识别语音中的情绪状态，结合多因子算法评估情绪稳定度，自动检测复合情绪模式，并给出个性化的分层调节建议。

系统采用**便携模式**设计，所有用户数据（录音、模型、历史记录、日志等）都保存在程序文件夹中，复制整个程序文件夹即可迁移所有数据，不污染系统目录。


> ⚠️ **免责声明**：本软件仅供个人非商用参考使用，检测结果仅作为情绪状态的辅助参考，不构成任何医疗诊断或建议。如有持续的情绪困扰，请及时咨询专业心理医生。

## 🧬 核心算法与技术原理

### 情绪识别模型（emotion2vec+）

本系统使用阿里达摩院开发的 **emotion2vec+** 系列预训练模型，基于大规模语音情感数据训练，支持端到端的语音情绪识别。

| 模型 | 参数规模 | 速度 | 精度 | 适用场景 |
|------|----------|------|------|----------|
| emotion2vec_plus_seed | ~1.1GB | ⚡⚡⚡ 最快 | ★★★ | 低配置设备、快速体验 |
| emotion2vec_plus_base | ~1.1GB | ⚡⚡ 均衡 | ★★★★ | 日常使用、精度与速度兼顾 |
| emotion2vec_plus_large | ~1.9GB | ⚡ 较慢 | ★★★★★ | 精度优先（推荐） |

**模型输出**：8 种基础情绪分类的概率分布

```
angry → 愤怒    disgusted → 厌恶    fearful → 恐惧    happy → 开心
neutral → 平静    other → 其他    sad → 悲伤    surprised → 惊讶
```

### 情绪稳定度评分算法

系统采用**三因子加权评分模型**计算情绪稳定度分数（0-10 分，越高越不稳定）：

```
最终分数 = 负面情绪加权分 × 0.40 + 情绪熵值分 × 0.30 + 情绪极端度分 × 0.30
```

**因子 1：负面情绪加权分数（权重 40%）**

各情绪对不稳定度的贡献权重：

| 情绪 | 权重 | 心理学依据 |
|------|------|-----------|
| 恐惧 | 0.95 | 高唤醒度，最强的应激反应 |
| 愤怒 | 0.90 | 高激活负面情绪 |
| 悲伤 | 0.80 | 低激活但持续影响心理状态 |
| 厌恶 | 0.70 | 中等负面影响 |
| 惊讶 | 0.30 | 短暂激活，影响有限 |
| 其他 | 0.15 | 未识别，轻微贡献 |
| 开心/平静 | 0.00 | 正面/中性情绪无负面贡献 |

**因子 2：情绪分散度 / Shannon 熵（权重 30%）**

使用 Shannon 信息熵衡量情绪概率分布的混乱程度：

```
H = -Σ p(i) × log₂(p(i))    归一化到 0-10
```

高熵值意味着多种情绪并存、情绪状态不明确，提示心理冲突。

**因子 3：情绪极端度（权重 30%）**

检测是否存在极端高概率的负面情绪：
- 单一负面情绪概率 > 60%：极端不稳定
- 单一负面情绪概率 > 40%：中等不稳定
- 正面情绪占主导时自动降低不稳定度

**稳定度等级划分：**

| 分数区间 | 等级 | 含义 |
|----------|------|------|
| 0.0 - 2.0 | 非常稳定 🟢 | 心态平和，情绪健康 |
| 2.0 - 3.5 | 良好 🟢 | 轻微波动，属正常范围 |
| 3.5 - 5.0 | 一般 🟡 | 有一定情绪波动 |
| 5.0 - 6.5 | 轻度波动 🟠 | 需要关注情绪状态 |
| 6.5 - 8.0 | 不稳定 🔴 | 情绪波动明显 |
| 8.0 - 10.0 | 情绪激烈 🔴 | 强烈情绪，建议立即放松 |

### 复合情绪识别机制

复合情绪由多种基础情绪在特定模式下组合而成。当各组成情绪的概率均超过阈值（10%）时，触发复合情绪检测：

| 复合情绪 | 组成模式 | 心理学描述 |
|----------|----------|-----------|
| **焦虑** | 恐惧 + 悲伤 | 恐惧与悲伤交织，对未来的不确定感和持续担忧 |
| **挫败** | 愤怒 + 悲伤 | 愤怒与悲伤并存，源于期望落空或目标受阻 |
| **嫉妒** | 愤怒 + 悲伤 + 恐惧 | 三重交织，涉及对自身地位的不安 |
| **紧张** | 恐惧 + 惊讶 | 面对未知挑战时的应激反应 |
| **厌倦** | 厌恶 + 悲伤 | 源于长期重复或缺乏意义感 |
| **愤恨** | 愤怒 + 厌恶 | 强烈的排斥和对抗情绪 |

多个复合情绪同时满足条件时，系统选择组成情绪总概率最高的作为最终结果。

## 🚀 快速开始

### 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / Windows 11 |
| Python 版本 | 3.8 ~ 3.11 |
| 内存 | 建议 4GB 以上 |
| 磁盘空间 | 建议 3GB 以上（单个模型约 1~2GB，按需下载模型数量增加） |
| 音频设备 | 可用的麦克风 |

### 安装步骤

1. **克隆或下载项目**

```bash
git clone https://github.com/lijiawei255/voice-mood-detector.git
cd Voice_Mood_Detect
```

2. **创建虚拟环境（推荐）**

```bash
python -m venv venv
# Windows
venv\Scripts\activate
```

3. **安装依赖**

```bash
pip install -r requirements.txt
```

> 💡 **提示**：如果 PyAudio 安装失败，可以尝试使用 conda 安装：
> ```bash
> conda install pyaudio -y
> ```

### 运行程序

```bash
python main.py
```

## 📖 使用指南

### 首次运行（模型下载）

1. 首次启动程序时，会显示**欢迎向导**，介绍系统功能和使用方法
2. 点击「🚀 开始使用（下载模型）」按钮
3. 程序会自动从 ModelScope 下载 **emotion2vec_plus_large** 模型（默认）
4. 模型大小约 **1GB**，请耐心等待下载完成
5. 下载完成后模型会保存在 `portable_data/models/` 目录中
6. 以后启动程序会直接加载本地模型，无需重新下载

### 录音与分析

1. 等待模型加载完成（状态栏显示「● 准备就绪」）
2. 点击绿色的 **「🎤 点击开始录音」** 按钮
3. 自然地说出您现在的感受（建议录音时长 3-30 秒）
4. 点击红色的 **「⏹️ 点击停止录音」** 按钮
5. 稍等几秒，即可看到分析结果

### 科研评估模式

1. 在录音控制区选择 **「科研评估」** 模式
2. 点击 **「开始科研评估」** 按钮
3. 系统会先进行约 3 秒的环境噪声检测
4. 按提示用统一内容录制 3 段语音（每段建议 10-30 秒）
5. 每段录音会通过音频质量门控；不满足要求时可重新录制
6. 完成 3 段采样后，系统输出：
   - 每段样本的详细情绪分析
   - 会话主要情绪与稳定度均值
   - 多次采样一致性 / 综合可靠性
   - 可选的 Large↔Base 双模型规模敏感性验证

### 结果说明

- **情绪稳定度**：0-10 分，分数越高表示情绪波动越大
  - 0-2 分：非常稳定 🟢
  - 2-3.5 分：良好 🟢
  - 3.5-5 分：一般 🟡
  - 5-6.5 分：轻度波动 🟠
  - 6.5-8 分：不稳定 🔴
  - 8-10 分：情绪激烈 🔴

- **主要情绪**：愤怒、厌恶、恐惧、开心、平静、悲伤、惊讶、其他
- **混合情绪**：同时检测到的其他情绪（概率 > 8%）
- **复合情绪**：由基础情绪组合而成的高级情绪状态
- **VAD 维度**：效价(Valence)、唤醒度(Arousal)、掌控感(Dominance)、负性负荷
- **稳定度因子**：负面加权、情绪分散度(熵)、极端度三因子分项
- **声学特征**：F0、jitter、shimmer、HNR、语速、静音比等
- **心理状态指标**：压力、焦虑、低落倾向、情绪激活度、语音稳定性（非临床诊断）
- **可靠性**：综合音频质量、置信度与一致性的高/中/低评级
- **个人基线偏移**：相对已建立个人基线的 z-score 偏移
- **调节建议**：基于情绪状态的分层建议（即时 + 长期）

### 模型切换

系统支持三种规格的模型，可根据设备性能选择：
- **Seed（最小模型）**：~1.1GB，适合低配置设备
- **Base（基础模型）**：~1.1GB，速度与精度均衡
- **Large（大型模型）**：~1.9GB，精度最高（推荐）

### 个人基线校准

1. 在右侧 **「个人基线管理」** 面板点击 **「采集基线样本」**
2. 用平静、放松的状态录制 5-10 秒语音
3. 重复 3-10 次以建立稳定的个人基线
4. 建立基线后，后续实时检测将同时显示绝对分数和相对基线偏移

### 历史记录

1. 点击顶部的 **「📋 历史报告」** 标签页
2. 查看所有历史检测记录（按时间倒序排列）
3. 下方显示**情绪稳定度变化趋势图**
4. 记录序号按时间先后排列（第 1 次、第 2 次...）

### 数据管理

1. 点击顶部菜单 **「文件 → 数据管理」**（快捷键 Ctrl+D）
2. 查看数据存储位置和存储空间统计
3. 支持的操作：
   - **清空所有历史记录和录音**：删除所有检测记录和音频文件
   - **一键清理系统垃圾**：清除临时文件、缓存文件、日志文件
   - **打开数据文件夹**：在文件管理器中打开数据目录

### 程序卸载

由于采用便携模式，卸载非常简单：

1. 关闭程序
2. 直接删除整个程序文件夹即可
3. 不会在系统中留下任何残留文件
